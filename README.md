# Formação IA Generativa

Repositório com exemplos e exercícios práticos da minha jornada de aprendizado em IA Generativa.

## Objetivo

Este projeto reúne scripts simples para praticar fundamentos de Python e preparar o ambiente para atividades de análise e visualização de dados.

## Estrutura do Projeto

- `exemplo_hello_world.py`: script inicial com variáveis e saída no terminal.
- `requirements.txt`: dependências Python do projeto.
- `executar.bat`: arquivo para facilitar execução no Windows (pode ser ajustado conforme necessidade).

## Pré-requisitos

- Python 3.10+ (recomendado)
- pip

## Como executar

### 1) Clonar o repositório

```bash
git clone https://github.com/SandroHeleno/formacao-ia-generativa.git
cd formacao-ia-generativa
```

### 2) Criar e ativar ambiente virtual (recomendado)

#### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

#### Windows (PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3) Instalar dependências

```bash
pip install -r requirements.txt
```

### 4) Rodar exemplo

```bash
python exemplo_hello_world.py
```
